# 🍝 Sapore Italiano - Web Oficial

Web oficial del restaurante **Sapore Italiano** en Coín, Málaga.

## 🌐 URL
https://sapore-web.vercel.app

## ✨ Características

- **Inicio** - Página principal con información y ubicación
- **Carta** - Menú completo con secciones desplegables
- **Pedidos Online** - Sistema de pedidos Take Away
- **Lista de Deseos** - Guarda platos favoritos para mostrar al camarero
- **Autenticación** - Registro e inicio de sesión de clientes

## 🛠️ Tecnologías

- React + Vite
- Lucide Icons
- Baserow (Base de datos)
- Vercel (Hosting)

## 🔗 APIs

- Backend: https://sapore-italiano-backend.vercel.app/api
- Baserow: Base de datos privada
